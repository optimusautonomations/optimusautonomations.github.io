# Optimus Automation International Landing Page

[![Deploy Next.js site to Pages](https://github.com/optimusautonomations/optimusautonomations.github.io/actions/workflows/nextjs.yml/badge.svg)](https://github.com/optimusautonomations/optimusautonomations.github.io/actions/workflows/nextjs.yml)

A production-ready Next.js App Router landing page for Optimus Automation International Pvt Ltd, built with React, TypeScript, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open `http://optimusautonomations.github.io` to view the site.
